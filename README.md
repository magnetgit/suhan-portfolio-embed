# 이수한 포트폴리오 · 노션 임베드용 사본

원본 포트폴리오(https://suhan-dev-notebook.llsshh1510.chatgpt.site/)를 노션 임베드 칸에 맞게 섹션별로 나눠 보여주는 사본입니다.

- 조각 목록: `embed.html`
- 조각 하나 보기: `embed.html?part=tripa-video` 처럼 `part`에 이름을 넣습니다.
- `index.html`, `style.css`, `video.js`, `media/`는 원본 `dist`의 사본입니다. 원본이 바뀌면 이 파일들을 다시 복사합니다.
- 조각 나누는 규칙은 `embed.html`의 `PARTS`에 있습니다.
